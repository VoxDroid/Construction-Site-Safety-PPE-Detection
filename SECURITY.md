# Security policy

## Supported versions

Security fixes go into the latest release.

## Reporting a vulnerability

Please report security problems privately through
[GitHub security advisories](https://github.com/VoxDroid/ppe-guard/security/advisories/new),
not in a public issue. Include the version, how to reproduce it and what an attacker could do.
You should get a reply within a week.

## Running PPE Guard safely

The dashboard shows live video and can change settings. Before making it reachable from other
machines, set a password (`ppe-guard password set`) and use HTTPS or a VPN for remote access.
See the [security guide](https://voxdroid.github.io/ppe-guard/guide/security/).
